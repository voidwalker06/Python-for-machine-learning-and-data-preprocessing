WEEK 1 PROJECT: PYTHON FOR MACHINE LEARNING & DATA PREPROCESSING

FILES
1. student_performance_raw.csv
   The sample dataset containing intentional missing values.
2. preprocessing_project.py
   Complete Python script for the preprocessing workflow.
3. Week1_ML_Data_Preprocessing.ipynb
   Notebook version with explanations and code cells.
4. Week1_Project_Report.docx
   Written report describing the objectives, dataset, steps, and outcome.

REQUIREMENTS
Python 3
Install libraries:
    pip install pandas numpy matplotlib scikit-learn notebook

HOW TO RUN THE SCRIPT
Keep the CSV and Python script in the same folder, then run:
    python preprocessing_project.py

HOW TO OPEN THE NOTEBOOK
Open a terminal in this folder and run:
    jupyter notebook
Then open Week1_ML_Data_Preprocessing.ipynb.

OUTPUT
The script creates an output folder containing:
- student_performance_cleaned.csv
- final_score_distribution.png
- numeric_correlation.csv

NOTE
The dataset is synthetic and intended for educational practice. The task demonstrates
data preprocessing; it does not train a machine learning model.
